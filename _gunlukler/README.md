# Günlük yazıları

Her günlük için bu klasörde `2025-07-20-ilk-gunlugum.md` gibi bir dosya oluştur.
Başlığı, tarihi ve metni kendi yazına göre değiştir.

```markdown
---
title: İlk günlüğüm
date: 2025-07-20
---

Günlük yazını buraya Markdown biçiminde yaz.
```

Yazılar yayımlandığında sitenin **Günlükler** sayfasında en yeni tarih üstte olacak şekilde listelenir.
